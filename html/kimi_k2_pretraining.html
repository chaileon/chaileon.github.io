Optimal Parallelization Strategy

Recommended Configuration — 240 GPUs
Dimension Symbol Value Rationale
Tensor Parallelism TP 8 One full NVLink domain per node (900 GB/s); splits QKV projections and FFN weight matrices across 8 GPUs. No cross-node bandwidth penalty.
Pipeline Parallelism PP 6 30 nodes ÷ 5 DP replicas = 6 nodes per pipeline. Partitions 61 layers into ~10 layers/stage (stages 1–5: 10 layers each; stage 6: 11 layers + LM head). Bubble fraction = 5/64 ≈ 7.8% with 64 micro-batches.
Data Parallelism DP 5 5 independent pipeline replicas. Gradient reduce-scatter via ZeRO Stage 2 over InfiniBand. Check: TP × PP × DP = 8 × 6 × 5 = 240 ✓
Expert Parallelism EP 8 EP = TP (same NVLink group). Each GPU holds 256 ÷ 8 = 32 routed experts per MoE layer. All2All for token dispatch uses high-BW NVLink; no cross-node expert traffic within a stage.
Sequence Parallelism SP ON Paired with TP=8; splits sequence dimension across the TP group for LayerNorm and Dropout, reducing per-GPU activation memory by ~8×.
ZeRO Stage ZeRO 2 Shards optimizer states and gradients across DP=5, cutting optimizer memory by 5×. Full param replication preserved for fast AR access pattern.
