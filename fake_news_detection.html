Load Gemma 4 (1B)

Gemma 4 is Google's open-weights language model family. The 1B (1-billion parameter) instruction-tuned variant is the smallest and fastest — perfect for experimentation on a free GPU.

Cell 3 — Load Gemma 4 1B
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig, pipeline

MODEL_ID = "google/gemma-4-1b-it"

# 4-bit quantization: loads the model in ~1 GB instead of ~2 GB, with minimal quality loss
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

print("Loading tokenizer...")
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)

print("Loading model (this may take 1-2 minutes)...")
model = AutoModelForCausalLM.from_pretrained(
    MODEL_ID,
    quantization_config=bnb_config,
    device_map="auto",
)
model.eval()

# Wrap in a pipeline for easy use
generator = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=300,
    do_sample=False,          # deterministic output
    temperature=1.0,
    repetition_penalty=1.1,
)

print("✓ Gemma 4 1B loaded and ready!")
What is quantization? Language models store billions of decimal numbers (weights). Quantization compresses each number from 16 bits down to 4 bits, shrinking the model to roughly a quarter of its original size in memory. Quality drops very slightly, but it lets you run models that would otherwise not fit on a free GPU.

Fetch Article Content from URLs

Before the model can analyse a news article, we need to download the page and extract the readable text from the HTML. We use requests to fetch the page and BeautifulSoup to parse it.

Cell 5 — Article fetcher
import requests
from bs4 import BeautifulSoup

def fetch_article(url: str, max_chars: int = 3000) -> dict:
    """Download a URL and return its title + body text."""
    headers = {"User-Agent": "Mozilla/5.0 (compatible; FakeNewsBot/1.0)"}
    try:
        resp = requests.get(url, headers=headers, timeout=10)
        resp.raise_for_status()
    except requests.RequestException as e:
        return {"url": url, "title": "ERROR", "body": str(e)}

    soup = BeautifulSoup(resp.text, "html.parser")

    # Extract title
    title_tag = soup.find("title")
    title = title_tag.get_text(strip=True) if title_tag else "No title found"

    # Remove non-content tags
    for tag in soup(["script", "style", "nav", "footer", "aside", "header"]):
        tag.decompose()

    # Grab paragraph text
    paragraphs = [p.get_text(separator=" ", strip=True) for p in soup.find_all("p")]
    body = " ".join(paragraphs)[:max_chars]

    return {"url": url, "title": title, "body": body}

# Test it
article = fetch_article("https://www.bbc.com/news")
print("Title:", article["title"])
print("Body preview:", article["body"][:200], "...")
Some websites block scrapers. If you get a 403 error or get back almost no text, the site may require JavaScript to render, use a paywall, or block bots. Try a different URL or use the datasets in Step 9 which provide pre-extracted text.

The Fake News Detection Pipeline

Now we wire everything together. The pipeline fetches an article, constructs a prompt, and asks Gemma 4 whether the article is real or fake.

Cell 6 — Detection pipeline
import json, re

PROMPT_TEMPLATE = """You are a professional fact-checking assistant helping to identify misinformation.

Carefully read the news article below and evaluate it.

--- ARTICLE ---
Title: {title}
URL: {url}
Content: {body}
--- END ARTICLE ---

Evaluate the article on the following criteria:
1. Does the headline match the content?
2. Are specific facts, names, dates, or statistics mentioned (good sign)?
3. Does the language use emotional exaggeration or alarming words (bad sign)?
4. Does the content make extraordinary claims without evidence?

Respond ONLY with a JSON object in this exact format:
{{
  "verdict": "REAL" or "FAKE" or "UNCERTAIN",
  "confidence": "LOW", "MEDIUM", or "HIGH",
  "red_flags": ["list", "of", "concerns"],
  "reason": "A 2-3 sentence explanation of your verdict."
}}"""

def detect_fake_news(url: str) -> dict:
    """Full pipeline: fetch article → prompt Gemma 4 → parse result."""
    print(f"  Fetching: {url}")
    article = fetch_article(url)

    if article["title"] == "ERROR":
        return {"url": url, "error": article["body"]}

    prompt = PROMPT_TEMPLATE.format(
        title=article["title"],
        url=url,
        body=article["body"],
    )

    print(f"  Analysing: {article['title'][:60]}...")
    raw_output = ask(prompt)

    # Try to parse the JSON response
    try:
        # Extract JSON block if model added extra text
        match = re.search(r"\{.*\}", raw_output, re.DOTALL)
        result = json.loads(match.group()) if match else {"raw": raw_output}
    except (json.JSONDecodeError, AttributeError):
        result = {"raw": raw_output}

    result["url"] = url
    result["title"] = article["title"]
    return result


def print_result(r: dict):
    verdict = r.get("verdict", "UNKNOWN")
    colour = {"REAL": "✅", "FAKE": "🚫", "UNCERTAIN": "⚠️"}.get(verdict, "❓")
    print(f"\n{colour}  {verdict}  [{r.get('confidence', '?')} confidence]")
    print(f"    Title : {r.get('title', 'N/A')[:70]}")
    print(f"    Reason: {r.get('reason', r.get('raw', 'N/A'))[:200]}")
    flags = r.get("red_flags", [])
    if flags:
        print(f"    Flags : {', '.join(flags)}")
    print(f"    URL   : {r['url']}")

Evaluate Your Results

Saying "the model classified an article as FAKE" is not very meaningful on its own. Good science requires measuring how accurate and consistent your classifier is. Use a labelled dataset (see Step 9) where you already know the ground truth.

Cell 8 — Compute accuracy
def evaluate(labelled_samples: list[dict]) -> None:
    """
    labelled_samples: list of {"url": "...", "label": "REAL" or "FAKE"}
    """
    correct, total, skipped = 0, 0, 0

    for sample in labelled_samples:
        print(f"\nGround truth: {sample['label']}")
        r = detect_fake_news(sample["url"])
        print_result(r)

        predicted = r.get("verdict")
        if predicted in ("REAL", "FAKE"):
            total += 1
            if predicted == sample["label"]:
                correct += 1
        else:
            skipped += 1   # UNCERTAIN or parse error

    accuracy = correct / total if total > 0 else 0
    print(f"\n{'='*40}")
    print(f"Accuracy : {accuracy:.1%}  ({correct}/{total} correct)")
    print(f"Skipped  : {skipped} (UNCERTAIN / parse error)")


# Example with known labels — replace with your own
labelled = [
    {"url": "https://www.bbc.com/news/world",    "label": "REAL"},
    {"url": "https://www.reuters.com/world/",    "label": "REAL"},
    # {"url": "https://...",                      "label": "FAKE"},
]
evaluate(labelled)
Think about these questions: Does accuracy alone tell the whole story? What happens if 90% of your test articles are real — could a dumb classifier that always says "REAL" score 90%? Look up precision, recall, and F1 score for a more complete picture.

Going Further — Hints & Techniques

Once the basic pipeline works, here are three techniques to make it significantly better. Expand each card to learn more.

🎯
Prompt Engineering
Craft better instructions to dramatically improve accuracy
Beginner ▼

The single biggest lever you have is the prompt — the instructions you give the model. Small wording changes can shift accuracy by 10-20 percentage points.

Technique 1: Zero-shot vs Few-shot

Zero-shot (what you did above) gives the model no examples. Few-shot shows it 2-3 examples of fake and real articles inside the prompt so it calibrates its judgement.

Few-shot prompt example
FEW_SHOT_EXAMPLES = """
Here are two example classifications:

EXAMPLE 1 (REAL):
Title: "Central bank raises interest rates by 0.25%"
Content: "The Federal Reserve raised its benchmark rate by a quarter point on Wednesday,
citing persistent inflation. Chair Jerome Powell said..."
Result: {"verdict": "REAL", "confidence": "HIGH", "reason": "Specific institution, named official, and verifiable policy action."}

EXAMPLE 2 (FAKE):
Title: "Scientists PROVE 5G towers cause cancer — government hiding it!!"
Content: "A SHOCKING new study that big pharma doesn't want you to see reveals..."
Result: {"verdict": "FAKE", "confidence": "HIGH", "reason": "Sensational language, vague unnamed study, conspiracy framing."}

Now classify this article:
"""

Technique 2: Chain-of-Thought (CoT)

Ask the model to think step by step before giving its verdict. This forces it to reason rather than guess.

Chain-of-thought prompt addition
COT_SUFFIX = """
Before giving your JSON verdict, think through these questions:
Step 1: What specific factual claims are made?
Step 2: Are sources named and verifiable?
Step 3: What is the emotional tone of the writing?
Step 4: Does the headline match the body?

After your thinking, output the JSON verdict on the last line.
"""

Technique 3: Red-flag vocabulary

Give the model a list of phrases commonly found in fake news to help it pattern-match. Examples: "you won't believe", "mainstream media won't tell you", "SHOCKING", "wake up sheeple", "100% proven", "sources say" (without names).

Experiment: Run the same set of 10 articles with your original prompt and your improved prompt. Compare accuracy. This is called an ablation study — a real technique used in AI research.
🔁
SelfCheckGPT — Consistency Sampling
Run the model multiple times and measure disagreement
Intermediate ▼

SelfCheckGPT is a technique from a 2023 research paper (Manakul et al.) that detects when a model is hallucinating or uncertain by sampling the same prompt multiple times at different temperatures and measuring how consistent the answers are.

The intuition is simple: if the model is confident and correct, it will give the same answer every time. If it gives different answers, it is uncertain — and uncertain answers deserve less trust.

SelfCheckGPT implementation
from collections import Counter

# Re-create the pipeline with sampling enabled for this technique
sampling_generator = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=300,
    do_sample=True,     # Enable randomness
    temperature=0.8,    # Controls randomness (0 = deterministic, 1 = creative)
)

def selfcheck_detect(url: str, num_samples: int = 5) -> dict:
    """Run the model N times and report the majority vote + consistency score."""
    article = fetch_article(url)
    prompt = PROMPT_TEMPLATE.format(**article, url=url)
    messages = [{"role": "user", "content": prompt}]

    verdicts = []
    for i in range(num_samples):
        output = sampling_generator(messages)
        raw = output[0]["generated_text"][-1]["content"]
        try:
            match = re.search(r'"verdict"\s*:\s*"(\w+)"', raw)
            verdict = match.group(1) if match else "UNCERTAIN"
        except AttributeError:
            verdict = "UNCERTAIN"
        verdicts.append(verdict)
        print(f"  Sample {i+1}: {verdict}")

    counts = Counter(verdicts)
    majority_verdict, majority_count = counts.most_common(1)[0]
    consistency = majority_count / num_samples  # 1.0 = all samples agree

    return {
        "url": url,
        "title": article["title"],
        "verdict": majority_verdict,
        "confidence": "HIGH" if consistency >= 0.8 else ("MEDIUM" if consistency >= 0.6 else "LOW"),
        "consistency": f"{consistency:.0%}",
        "all_verdicts": verdicts,
        "reason": f"Majority vote from {num_samples} samples: {dict(counts)}"
    }

# Test it
r = selfcheck_detect("https://www.bbc.com/news/world", num_samples=3)
print_result(r)
print(f"Consistency: {r['consistency']}")
Why does this help? A model may confidently say "FAKE" once by chance. But if you ask it 5 times and it says FAKE 4 out of 5, you have much stronger evidence. A 60/40 split (REAL vs FAKE) tells you the article is genuinely ambiguous — which itself is useful information.
🤖
Multi-Agent Pipeline
Decompose the task into specialised sub-agents
Advanced ▼

Instead of asking one model to do everything, break the task into specialised agents, each with a narrow, clear job. The outputs of earlier agents become the inputs to later ones.

This mirrors how a real newsroom fact-checks a story: one person extracts the claims, another checks each claim independently, a third writes the verdict. Specialisation improves quality.

Multi-agent architecture
def agent_extract_claims(article_text: str) -> list[str]:
    """Agent 1: Extract specific factual claims from the article."""
    prompt = f"""Read the article below and list up to 5 specific factual claims made in it.
A factual claim is a statement that could, in principle, be verified (e.g. a statistic,
a named person doing something, an event happening on a date).

Article: {article_text[:2000]}

Output a numbered list of claims only. No other text."""
    raw = ask(prompt)
    # Parse numbered list
    claims = re.findall(r'\d+\.\s+(.+)', raw)
    return claims if claims else [raw]


def agent_evaluate_claim(claim: str) -> dict:
    """Agent 2: Evaluate a single claim for plausibility."""
    prompt = f"""You are a fact-checker. Evaluate this single claim:
"{claim}"

Does this claim:
- Sound plausible based on general knowledge?
- Use specific verifiable details (names, dates, numbers)?
- Contain exaggerated or unverifiable language?

Respond with JSON: {{"plausible": true/false, "reason": "one sentence"}}"""
    raw = ask(prompt)
    try:
        match = re.search(r'\{.*\}', raw, re.DOTALL)
        return json.loads(match.group()) if match else {"plausible": None, "reason": raw}
    except (json.JSONDecodeError, AttributeError):
        return {"plausible": None, "reason": raw}


def agent_aggregate(title: str, claim_results: list[dict]) -> dict:
    """Agent 3: Aggregate individual claim verdicts into an overall verdict."""
    summary = "\n".join(
        f"- Claim: {r.get('claim','?')} → Plausible: {r.get('plausible')} ({r.get('reason','')})"
        for r in claim_results
    )
    prompt = f"""You are the editor reviewing a fact-check report.

Article title: {title}

Individual claim evaluations:
{summary}

Based on these results, give an overall verdict.
Respond with JSON: {{"verdict": "REAL"/"FAKE"/"UNCERTAIN", "confidence": "LOW"/"MEDIUM"/"HIGH", "reason": "2-3 sentences"}}"""
    raw = ask(prompt)
    try:
        match = re.search(r'\{.*\}', raw, re.DOTALL)
        return json.loads(match.group()) if match else {"verdict": "UNCERTAIN", "reason": raw}
    except (json.JSONDecodeError, AttributeError):
        return {"verdict": "UNCERTAIN", "reason": raw}


def multi_agent_detect(url: str) -> dict:
    """Full 3-agent pipeline."""
    print(f"\n[Agent 0] Fetching article...")
    article = fetch_article(url)

    print("[Agent 1] Extracting claims...")
    claims = agent_extract_claims(article["body"])
    print(f"  Found {len(claims)} claims: {claims[:2]}...")

    print("[Agent 2] Evaluating each claim...")
    claim_results = []
    for claim in claims:
        result = agent_evaluate_claim(claim)
        result["claim"] = claim
        claim_results.append(result)
        print(f"  → {claim[:50]}: plausible={result.get('plausible')}")

    print("[Agent 3] Aggregating verdict...")
    final = agent_aggregate(article["title"], claim_results)
    final["url"] = url
    final["title"] = article["title"]
    final["claims_checked"] = len(claims)
    return final

# Run the multi-agent pipeline
r = multi_agent_detect("https://www.bbc.com/news/world")
print_result(r)
print(f"Claims checked: {r.get('claims_checked', 0)}")
Going even further: Add a fourth agent that searches Google News to see if other reputable outlets are reporting the same story. Cross-referencing sources is one of the most reliable fake news signals used by professional fact-checkers.

Challenge Extensions

Finished the core project? Push your work further with these open-ended challenges:

Easy   Visualise results

Use matplotlib to plot a bar chart of REAL vs FAKE verdicts, or a confusion matrix comparing your predictions against the ground truth labels.

Easy   Add source credibility scoring

Extract the domain name from each URL and compare it against a known list of reliable outlets (BBC, Reuters, AP News) or low-credibility sites. Use this as an additional signal in your prompt.

Medium   Compare model sizes

Run the same evaluation using google/gemma-4-4b-it (4B parameters). Does accuracy improve? How much slower is it? Is the extra quality worth the extra compute?

Medium   Fine-tune on a small dataset

Use HuggingFace PEFT and LoRA to fine-tune Gemma 4 1B on 1,000 labelled examples. Fine-tuning can dramatically outperform prompting for well-defined classification tasks.

Hard   Build a browser extension

Wrap your pipeline in a lightweight Flask API, host it on a free service like Hugging Face Spaces, and build a Chrome extension that automatically checks the current page you are reading.

Hard   Real-time Twitter / X monitoring

Use the Twitter API to collect trending news URLs and run them through your pipeline automatically, flagging high-confidence FAKE results for human review.

For your project write-up, consider: What are the ethical implications of automated fake news detection? What happens when the model is wrong? Who is harmed by false positives (labelling real news as fake) vs false negatives (missing actual fake news)?
