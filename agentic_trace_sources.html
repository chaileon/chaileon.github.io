Corpus survey · compiled 30 August 2026

Agentic Trace Atlas

Every open-source agentic trace corpus we could locate, for post-training a general multimodal agent. Each Hugging Face entry was checked live against the Hub API — availability, gating, declared license, paginated download size, and the harness the traces were recorded under — rather than taken from a paper or a search result. A ✓ on a harness means it was confirmed in the dataset card; everything else is inferred or unverified.

Concentration sits in one unnamed scaffold

togethercomputer/CoderForge-Preview alone is 73 GB — roughly a quarter of all measured trace bytes — and its card states it was generated with a single scaffold and fixed tool set, no permutations, warning that models fine-tuned on it "may perform worse when deployed with different scaffolds, tools, prompt formats".

OpenHands is broad, not dominant

Seven corpora use it, but they are individually small: about 11% of measured bytes. Add the OpenHands portion of the multi-harness Open-SWE-Traces and it reaches roughly a fifth — widespread enough to bias format priors, far from a majority.

Terminus-2 is the one deliberate convergence

AgentTrove, the Nemotron Terminal Corpus and the OpenThoughts agent sets all publish in the terminus-2 ShareGPT layout. It is the only format two independent groups adopted on purpose, which makes it the natural target if you normalize to one harness.

Train the permutation, not one scaffold

The Agent Data Protocol emits full_sft_openhands.jsonl, full_sft_sweagent.jsonl and full_sft_agentlab.jsonl from one normalized trace — the ready-made mechanism for rendering the same trajectory under several harnesses.

What verification turned up

Access is rarely the obstacle — nearly everything here downloads. Licensing and stale identifiers are the real friction, and both fail quietly.

The biggest security corpus is not public

The CAI Dataset describes 230,935 security agent sessions over 18 TB — an order of magnitude beyond everything openly available in that domain combined — but ships only to partner organisations and selected customers. The open security tier is small as a result, and jedisct1/security-audits at 35K runs is the practical ceiling.

Repository sizes need paginating

The Hub tree API returns only the first page of files. Two figures in the first edition of this atlas were badly undercounted as a result — osunlp/UGround-V1-Data is 424.5 GB, not 5.8, and mllmTeam/MobileViews is 475.5 GB, not 76.8. Every size here has since been re-measured by following the pagination cursor to the end.

Gating is a speed bump, not a wall

neulab/MultiUI, Salesforce/xlam-function-calling-60k, osunlp/UGround-V1-Data and osunlp/Mind2Web-2 return gated=auto, as does OS-Copilot/OS-Genesis-web-data outside this list. Each needs a one-time terms acceptance, after which downloads are fully scriptable.

Four high-value repositories declare no license

togethercomputer/CoderForge-Preview, xlangai/AgentTrek, AgentGym/AgentTraj-L and neulab/agent-data-collection ship without license metadata. Absent a declaration, treat them as all rights reserved and clarify with the authors before commercial training.

Three widely-cited dataset IDs do not exist

Papers commonly cite agent-trek/AgentTrek-1.0, ScaleCUA/ScaleCUA-Data and Salesforce/xlam-traces. The first two resolve to xlangai/AgentTrek and OpenGVLab/ScaleCUA-Data; the third has no public release at all. These would fail silently in a bulk download script.

Two repositories return empty root listings

vyokky/GUI-360 and McGill-NLP/A3-Synth show no files at the tree API root — their content sits in subfolders or is awaiting parquet conversion. Both resolve correctly through hf download.

Non-commercial licenses

osunlp/UGround-V1-Data, McGill-NLP/WebLINX and Salesforce/APIGen-MT-5k are all NC-licensed and cannot be used to train a commercially deployed model.

Suggested ingestion order

Ordered by cost-to-value, not by size. The schema decision comes first because every later source has to pass through it.

  1. Fix the schema first

    Adopt the Agent Data Protocol from neulab/agent-data-collection as your internal trace format, so every later source normalizes into one pipeline instead of many bespoke loaders.

  2. Take the text agentic core

    Software engineering, terminal and tool-calling plus AgentTrove and Toucan. Cheap, permissively licensed, and enough for a competent text agent in roughly 120 GB.

  3. Add multimodal grounding

    AgentNet, Aguvis and OS-Atlas. This is where the multimodal capability actually comes from, and it is also where the storage cost lands.

  4. Extend to mobile

    Only if phone control is genuinely in scope — it is a large, domain-specific tier that will not transfer much to desktop.

  5. Run the RL stage

    The verifier corpora above, plus rollouts you generate yourself from the environments.

Bulk fetch

Authentication is only needed for the gated entries.

pip install -U "huggingface_hub[cli]"
hf auth login
hf download <repo_id> --repo-type dataset --local-dir ./data/<name>

Sizes are full repository byte totals, obtained by following the Hub tree API pagination cursor to the end, otherwise the parquet-converted row and byte counts. Licenses are as declared in dataset card metadata — an absent declaration is recorded as unstated, not assumed permissive.
